# Responsive UI

## Design intent

The admin system needed to behave as a working tool on:

- desktop
- tablet
- mobile

The goal was not simply to shrink the desktop layout.

## Dashboard rules

- four KPI cards on wide screens
- two-column cards and quick actions on tablet
- single-column layout on mobile
- compact spacing and stronger hierarchy
- ranked actions before secondary analytics

## Management report rules

- four-column KPI cards on wide screens
- two-column cards and shortcuts on tablet
- single-column panels on mobile
- horizontally scrollable report navigation
- responsive filter and table handling

## Catalogue index rules

- compact summary cards
- clearer product image and model hierarchy
- grouped actions
- active-filter visibility
- responsive empty states
- mobile-safe table overflow

## Visual system

The interface used a restrained control-centre style:

- deep navy for structure
- gold for emphasis
- white and soft grey for readability
- limited warning accents
- status hierarchy instead of decorative noise

## Accessibility and truthfulness

Visual emphasis was used to communicate urgency, but labels still carried the meaning. Colour alone was not treated as the only status indicator.
